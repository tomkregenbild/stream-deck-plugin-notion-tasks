Create an internal integration and paste the secret token. Paste the database identifier (32 characters, without spaces). Select the Status property from your Notion database. Select which status value represents a completed task. Select the Due Date property from your Notion database. Select the Priority property from your Notion database (optional - enables color-coded buttons). Choose how to configure your priority system. Simple uses High/Medium/Low, Custom allows your own list, Legacy preserves original behavior. Enter your priority values in order from highest to lowest priority, separated by commas. Supports up to 20 priorities (colors will cycle after 10). Select which task slot (1-8) should appear on this key. Multiple keys can show the same task by using the same slot number. Click the key to mark the displayed task as complete.
